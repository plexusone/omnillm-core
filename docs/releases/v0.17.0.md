# Release Notes: v0.17.0

**Release Date:** 2026-06-15

## Highlights

- **Claude 4.5 Models**: Full model constant support for Claude Opus 4.5, Sonnet 4.5, and Haiku 4.5 across Bedrock and Vertex AI
- **Claude 4.x Updates**: Added missing Claude 4.1 and Sonnet 4 model constants for cloud providers

## Usage

```go
import (
    "github.com/plexusone/omnillm-core"
    "github.com/plexusone/omnillm-core/models"
)

// Using package-level constants
client.Model = omnillm.ModelBedrockClaudeOpus4_5

// Using models package directly
client.Model = models.BedrockClaudeOpus4_5
client.Model = models.VertexClaudeSonnet4_5
```
