# Release Notes: v0.17.0

**Release Date:** 2026-06-15

## Highlights

- **Claude Fable 5 & Mythos 5**: Support for Anthropic's latest frontier models
- **Claude 4.6-4.8**: Full model constant support across Claude API, Bedrock, and Vertex AI
- **Claude 4.5**: Complete coverage for Opus 4.5, Sonnet 4.5, and Haiku 4.5

## Deprecations

The following models are marked as deprecated per Anthropic's timeline:

| Model | Retirement Date |
|-------|-----------------|
| Claude Opus 4.1 | August 5, 2026 |
| Claude Opus 4 | June 15, 2026 |
| Claude Sonnet 4 | June 15, 2026 |

Migrate to Claude Opus 4.8 or Claude Sonnet 4.6 respectively.

## Usage

```go
import (
    "github.com/plexusone/omnillm-core"
    "github.com/plexusone/omnillm-core/models"
)

// Latest models
client.Model = omnillm.ModelClaudeFable5      // Frontier
client.Model = omnillm.ModelClaudeOpus4_8     // Latest Opus
client.Model = omnillm.ModelClaudeSonnet4_6   // Latest Sonnet

// Cloud providers
client.Model = models.BedrockClaudeOpus4_8
client.Model = models.VertexClaudeSonnet4_6
```

## Installation

```bash
go get github.com/plexusone/omnillm-core@v0.17.0
```
